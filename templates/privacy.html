개인정보처리방침

사주 간지 계산기(이하 "서비스")는 다음과 같이 개인정보를 처리합니다.

1. 수집하는 정보

생년월일시, 성별, 궁합 서비스 이용 시 입력한 이름(선택)은 사주·궁합 계산을 위해 서버로 전송되지만, 별도의 데이터베이스에 저장하지 않고 응답 후 즉시 폐기합니다. 계정 가입이나 로그인 기능이 없어 회원 정보를 보유하지 않습니다.

2. 쿠키·광고

서비스는 콘텐츠 페이지(명리 사전)에서 광고 네트워크의 쿠키를 사용할 수 있습니다. 광고 네트워크는 이용자의 관심사에 기반한 광고를 제공하기 위해 쿠키를 사용할 수 있으며, 브라우저 설정에서 쿠키 저장을 거부할 수 있습니다.

3. 외부 API

커플 궁합의 데이트 지역 추천 기능은 카카오 로컬 API를 호출해 식당·카페 정보를 조회합니다. 이 과정에서 지역명만 전송되며 개인 식별 정보는 전송하지 않습니다.

4. 문의

서비스 관련 문의는 GitHub 저장소 이슈로 남겨 주세요.
