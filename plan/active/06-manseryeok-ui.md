# 06. 만세력 스타일 결과 UI — 탭 구조 + 원국표 + 오행 다이어그램 + 대운·세운 확장

- **우선순위**: 🟡 중간 (05 완료 후 착수)
- **상태**: active
- **의존성**: 05(분석 엔진)의 API 확장(§7 JSON)이 선행되어야 함
- **참조**: 신한 SOL 만세력 스크린샷. 단, 시각 스타일은 우리 다크 명리 테마(saju.css)를 유지하고
  **정보 구조만** 차용한다 (레이아웃 모방 OK, 그대로 복제 금지).

---

## 1. 배경

현재 결과 화면은 "일주 히어로 + 네 기둥 + 오늘의 운세"의 바이럴형 구성이다.
참조 앱은 **탭 5개로 정보를 계층화**해 체류시간을 늘린다:
`사주원국 | 사주관계 | 오행과 십성 | 신강신약 | 대운수`

우리 결과 화면 하단(심층 리포트 자리)에 이 탭 구조를 넣으면
07 계획(콘텐츠·광고)의 "?" 툴팁을 달 표면적도 함께 생긴다.

## 2. 목표

1. 결과 화면에 **칩형 탭 내비게이션**(가로 스크롤)을 추가하고 5개 섹션을 렌더링.
2. 전부 05의 JSON만으로 렌더링 (프론트에서 명리 계산 금지 — 단일 진실 원천).
3. 모바일(412px) 기준, 기존 다크 테마 토큰(#D4B36A 골드, #0c0a16 배경) 재사용.

## 3. 섹션별 명세

### 3.1 사주원국 (기본 탭) — 8행 그리드 표

| 행 | 데이터 소스 (05 JSON) |
|---|---|
| 기둥 라벨 | 고정: 시주·말년운 / 일주·장년운 / 월주·청년운 / 년주·초년운 |
| 십성(천간) | `pillars.*.sipseong_stem` (일주는 "일원") |
| 천간 타일 | 기존 + `yin_yang_stem` → "-신,쇠金" 형식 부제 |
| 지지 타일 | 기존 + `yin_yang_branch` |
| 십성(지지) | `pillars.*.sipseong_branch` |
| 지장간 | `pillars.*.hidden_stems` (이미 있음) |
| 12운성 | `pillars.*.unseong12` |
| 12신살 | `pillars.*.sinsal12` |
| 공망 | `pillars.*.is_gongmang` → 해당 지지명 표시, 아니면 "-" |

- 열 순서는 참조 앱과 동일하게 **시→일→월→년** (기존 PILLAR_ORDER 재사용).
- 타일 색상은 기존 오행 색(EL_COLOR) 유지. 음양 부호는 타일 하단 작은 글씨.
- 시간 모름: 시주 열의 타일만 "시간 모름", **십성·12운성 등 나머지 행도 "-"**.

### 3.2 사주관계 — 서브탭 2개

- **천간과 지지**: `relations.stems` / `relations.branches`를 관계 카드 리스트로.
  카드 = `[종류 배지] 글자쌍 — 설명` (예: `[삼합] 해·미 — 해묘미 목국 반합`).
  관계 없으면 "특별한 합·충이 없어요" 빈 상태.
- **신살과 길성**: 천간 4타일 + 각 타일 아래 태그 목록(`gilseong.stems`),
  지지 4타일 + 태그 목록(`gilseong.branches`). 태그 없는 글자는 "-".
  길성(귀인·록)은 골드 배지, 살(殺)은 무채색 배지로 구분.

### 3.3 오행과 십성 — 오각형 SVG + 리스트

- **오각형 다이어그램** (inline SVG, 라이브러리 금지):
  - 정오각형 꼭짓점 5개에 원형 노드 (시계방향: 木→火→土→金→水).
  - 노드: 오행 한자 + `analysis.elements_pct` % 텍스트. 0%는 회색 처리.
  - 生 화살표: 인접 꼭짓점 실선 곡선 (목→화→토→금→수→목).
  - 剋 화살표: 별모양 대각선 점선 (목→토→수→화→금→목).
  - 구현 팁: 꼭짓점 좌표는 `cx + r*sin(72°k)`, `cy - r*cos(72°k)` 하드코딩 5쌍이면 충분.
- **오행 리스트 카드** 5개: `木 목(비겁) [적정배지] … 비견 12.5% / 겁재 12.5%`
  → `analysis.groups` + `analysis.element_status` + `analysis.sipseong_pct`.

### 3.4 신강신약

- `analysis.strength` → 게이지 바(0~1, 눈금: 극신약/신약/중화/신강/극신강) + 등급 텍스트.
- 득령/득지/득세 3칩 (충족=골드, 미충족=회색).
- 하단에 작은 글씨: "간이 판정 기준입니다" (§05-6.8 리스크 완화).

### 3.5 대운수 — 기존 대운/세운 확장

- 헤더: `대운수: N (순행|역행)` + "?" 툴팁 자리.
- 대운 카드(가로 스크롤, 기존 luck-row 패턴): 나이 / 십성(천간) / 천간타일 / 지지타일 /
  십성(지지) / 12운성 — 6단 세로 스택. 현재 대운은 점선 테두리 하이라이트(기존 current 로직).
- 세운 카드: 연도 / 십성 / 타일들 / 12운성. 현재 연도 하이라이트.
- 나이 표기: 현행 전통나이 유지하되 라벨을 "대운(세는나이)"로 명시
  (참조 앱은 만나이 — 05 §11 결정 반영).

## 4. 구현 파일

| 파일 | 작업 |
|---|---|
| `static/js/script.js` | `renderResult()` 하단에 탭 바 + 섹션 렌더러 5개 함수 추가 (`renderWongook`, `renderRelations`, `renderOhaeng`, `renderStrength`, `renderLuck`) |
| `static/css/saju.css` | `.sj-tabs`(칩 가로스크롤), `.sj-table`(원국 그리드), `.sj-badge-*`, `.sj-pentagon`, `.sj-gauge` 추가 |
| `templates/index.html` | 변경 없음 (JS 렌더링) |

- 탭 전환은 단순 `hidden` 토글 + `aria-selected`. URL 해시 연동은 선택.
- 심층 리포트 잠금(공유 유도)은 유지하되, 잠금 해제 시 탭 전체가 열리는 구조로 연결해도 좋음
  (바이럴 루프 유지 — 03 계획과 연계).

## 7. 검증 방법

1. 골든 케이스(1995 甲戌일생) 입력 → 스크린샷과 동일한 라벨이 5탭 전부에 표시.
2. 시간 모름 케이스 → 시주 열 전체 "-" 처리 확인.
3. Lighthouse 모바일 성능 저하 없음 (SVG 인라인, 외부 라이브러리 0).

## 8. 리스크

- 결과 화면이 길어져 스크롤 피로 → 탭이 해결. 단 탭 안 콘텐츠도 접기(아코디언) 고려.
- 표가 375px에서 넘칠 수 있음 → 원국 표는 `font-size` 축소 + 고정 4열 grid로 해결
  (참조 앱도 동일 접근).
