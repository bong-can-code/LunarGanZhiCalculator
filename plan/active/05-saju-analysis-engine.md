- **상태**: active
- **참조**: 신한 SOL 만세력 스크린샷 8장 (2026-07 사용자 제공). 본 문서의 모든 룰 테이블은
  스크린샷 값과 교차검증 완료.

## 1. 배경

참조 앱(만세력)은 우리가 이미 계산하는 4주 간지 위에 **명리 분석 레이어**를 얹어 제공한다.
스크린샷 분석 결과 필요한 구성요소와 현재 구현의 갭:

| 구성요소 | 참조 앱 | 현재 구현 | 갭 |
|---|---|---|---|
| 4주 간지 (천간/지지/한자/오행) | ✅ | ✅ `saju/pillars.py` | 없음 |
| 지장간 | ✅ | ✅ `saju/tables.py` | 없음 |
| 음양(+/-) 표기 | ✅ | ⚠️ 내부적으로만 | 표기용 필드 추가 |
| **십성(십신)** — 천간·지지별 | ✅ | ❌ | **신규** |
| **12운성** | ✅ | ❌ | **신규** |
| **12신살** | ✅ | ❌ | **신규** |
| **공망** | ✅ | ❌ | **신규** |
| **신살/길성** (귀인·살 ~10종) | ✅ | ❌ | **신규** |
| **합충형파해** (사주관계) | ✅ | ⚠️ `compat.py`에 일부 (육합/삼합/충/원진) | 확장·모듈 분리 |
| **오행 % + 십성그룹 + 상태배지** | ✅ | ⚠️ 개수만 (`count_elements`) | 확장 |
| **신강신약** | ✅ | ❌ | **신규** |
| 대운/세운 + 십성·12운성 라벨 | ✅ | ⚠️ 간지만 | 라벨 추가 |
| 기둥별 인생시기 라벨 (초년운 등) | ✅ | ❌ | 상수 추가 (UI) |

**중요한 통찰**: 위 항목은 전부 **머신러닝도, 외부 API도, 대용량 DB도 필요 없다.**
전원 (a) 소규모 룰 테이블(수십~수백 셀) + (b) 순수 함수 로직이다.
즉 "데이터 리서치 → 정제 → 자산화"는 **명리학 고전 규칙을 코드 상수로 옮기고,
스크린샷·참조 앱 값으로 교차검증한 뒤, pytest 골든 테스트로 잠그는 작업**이다.

## 3. 데이터 전략: 리서치 → 정제 → 자산화 파이프라인

### 3.1 왜 자산화가 가능한가

명리 규칙은 수백 년간 고정된 **결정론적 조합 규칙**이다. 저작권 문제도 없다
(고전 규칙 자체는 공유 지식; 특정 앱의 해석 "문장"만 베끼지 않으면 됨).

### 3.2 파이프라인 (각 테이블마다 동일하게 적용)

```
[1] 리서치   : 최소 2개 독립 출처에서 규칙 수집
              - 1차: 위키백과(십이운성, 십이신살, 신살, 공망 문서), 나무위키 명리 문서
              - 2차: 고전 명칭 확인 (연해자평, 자평진전 — 규칙 명칭·순서의 근거)
              - 3차: 참조 만세력 앱 2개 이상에서 샘플 사주 결과 대조
[2] 정제     : 유파 차이 발견 시 → "채택 기준" 결정하고 코드 주석에 대안 기록
[3] 자산화   : saju/tables_analysis.py 에 dict/tuple 상수로 인코딩 + 출처 주석
[4] 검증     : tests/test_analysis.py 골든 테스트 (본 문서 §4의 스크린샷 케이스 필수)
[5] 잠금     : 테스트 통과 후 테이블 수정 시 반드시 테스트도 함께 갱신 (회귀 방지)
```

### 3.3 이미 완료된 리서치 (본 문서 §6)

본 문서 §6의 모든 테이블은 **위 파이프라인 [1]~[2]를 거쳐 정제된 결과물**이다.
구현자는 §6을 그대로 코드로 옮기면 된다. 스크린샷 검증 근거는 각 표 아래 "검증" 줄 참고.

## 4. 골든 테스트 케이스 (스크린샷 역산) — 가장 중요

참조 스크린샷의 사주를 역산하면:

- **년주 乙亥 · 월주 丙戌 · 일주 甲戌 · 시주 辛未, 일간(일원) = 甲, 남성**
- 을해년=1995년, 술월=한로~입동(10월 초~11월 초), 甲戌일, 미시(13~15시).
- 구현 시 첫 작업: `korean-lunar-calendar`로 1995-10-09~11-07 사이 甲戌일을 찾아
  정확한 생년월일을 확정하고 테스트 픽스처로 기록한다. (60갑자 순환이므로 후보는 최대 1개)

이 한 사람에 대한 **전체 기대값** (모두 스크린샷에서 확인된 값):

| 항목 | 시주 辛未 | 일주 甲戌 | 월주 丙戌 | 년주 乙亥 |
|---|---|---|---|---|
| 십성(천간) | 정관 | 일원 | 식신 | 겁재 |
| 십성(지지) | 정재 | 편재 | 편재 | 편인 |
| 지장간 | 정을기 | 신정무 | 신정무 | 무갑임 |
| 12운성 | 묘 | 양 | 양 | 장생 |
| 12신살(년지 기준) | 화개 | 천살 | 천살 | 지살 |
| 공망 | - | - | - | - |

- 공망(일주 甲戌 기준) = **신(申)·유(酉)** → 사주 지지에 없으므로 전부 "-"
- 신살/길성: 辛→현침살, 甲→현침살, 丙→천덕귀인·월덕귀인·백호대살, 乙→없음,
  未→천을귀인·화개살, 戌(일지)→급각살·화개살, 戌(월지)→백호대살·화개살,
  亥→문곡귀인·학당귀인·암록
- 오행%: 木25.0 / 火12.5 / 土37.5 / 金12.5 / 水12.5 (8글자 × 12.5%)
- 십성그룹%: 비견12.5(일간 자신 포함!) 겁재12.5 / 식신12.5 상관0 / 편재25 정재12.5
  / 편관0 정관12.5 / 편인12.5 정인0
- 상태배지: 목=적정, 화=부족, 토=발달, 금=부족, 수=부족
- 대운: **역행**(음간 乙 + 남성), 대운(만) 표기 기준 0세 시작.
  0=乙酉, 10=甲申, 20=癸未, 30=壬午(현재·편인/상관/사), 40=辛巳, 50=庚辰, 60=己卯
- 세운: 2024 甲辰(비견/편재/쇠), 2025 乙巳(겁재/식신/병), 2026 丙午(식신/상관/사),
  2027 丁未(상관/정재/묘), 2028 戊申(편재/편관/절), 2029 己酉(정재/정관/태)

> **구현 지침**: `tests/test_analysis.py`에 위 표를 그대로 하드코딩한 골든 테스트를
> **코드 작성 전에 먼저** 만든다. 전부 통과하면 엔진 완성이다.

## 5. 모듈 설계

```
saju/
├── tables_analysis.py   # §6의 모든 룰 테이블 상수 (데이터 자산, 로직 없음)
├── sipseong.py          # 십성: sipseong_of(day_stem, target_stem) / branch용
├── unseong.py           # 12운성: unseong12_of(day_stem, branch)
├── sinsal.py            # 12신살 + 신살/길성 + 공망
├── relations.py         # 합충형파해 (compat.py의 기존 상수를 이쪽으로 이동, compat은 import)
└── strength.py          # 오행%/십성그룹/상태배지 + 신강신약 점수
```

함수 시그니처 (전부 순수 함수 — 입력은 한글 간지 문자, 출력은 한글 라벨):

```python
# sipseong.py
def sipseong_of(day_stem: str, target_stem: str) -> str: ...      # '비견'|'겁재'|...|'정인'
def sipseong_of_branch(day_stem: str, branch: str) -> str: ...    # 본기(정기) 기준
def sipseong_group(sipseong: str) -> str: ...                     # '비겁'|'식상'|'재성'|'관성'|'인성'

# unseong.py
def unseong12_of(day_stem: str, branch: str) -> str: ...          # '장생'|'목욕'|...|'양'

# sinsal.py
def sinsal12_of(base_branch: str, target_branch: str) -> str: ... # 년지(기본)/일지 기준
def gongmang_of(day_stem: str, day_branch: str) -> list[str]: ... # 공망 지지 2개
def gilseong_of(pillars: dict) -> dict: ...                       # {'stems': [[..]×4], 'branches': [[..]×4]}

# strength.py
def element_percentages(pillars: dict) -> dict: ...               # {'목': 25.0, ...}
def sipseong_breakdown(pillars: dict) -> dict: ...                # 십성별 % + 그룹 묶음
def element_status(count: int, total: int) -> str: ...            # '부족'|'적정'|'발달'|'과다'
def day_master_strength(pillars: dict) -> dict: ...               # {'score', 'grade', 'details'}

# relations.py
def stem_relations(stems: list[str]) -> list[dict]: ...           # 천간합/충
def branch_relations(branches: list[str]) -> list[dict]: ...      # 육합/삼합/방합/충/형/파/해/원진
```

**설계 원칙 (낮은 등급 모델을 위한 가이드)**:
1. 테이블은 전부 `tables_analysis.py`에, 로직 파일에는 dict 리터럴 금지.
2. 함수 하나 = 조회 1~3회 + 인덱스 연산. 10줄 넘으면 잘못 설계한 것.
3. 모든 인덱스 연산은 기존 `gapja.py`의 `HEAVENLY_STEMS.index()` 패턴을 따른다.
4. 예외 상황(시주 None)은 호출부(calculator)에서 걸러서 넘긴다. 분석 함수는 None을 받지 않는다.

## 6. 룰 테이블 (정제 완료된 데이터 자산)

### 6.1 십성(十星) — 유도 규칙 (테이블 불필요, 5행 규칙으로 계산)

기준: 일간(day stem)과 대상 글자의 **오행 관계** × **음양 일치 여부**.

| 오행 관계 (일간 → 대상) | 음양 같음 | 음양 다름 |
|---|---|---|
| 같은 오행 | 비견 | 겁재 |
| 일간이 生 하는 오행 (식상) | 식신 | 상관 |
| 일간이 剋 하는 오행 (재성) | 편재 | 정재 |
| 일간을 剋 하는 오행 (관성) | 편관 | 정관 |
| 일간을 生 하는 오행 (인성) | 편인 | 정인 |

- 생(生) 순환: 목→화→토→금→수→목. 극(剋) 순환: 목→토→수→화→금→목.
- 천간 음양: 갑+ 을- 병+ 정- 무+ 기- 경+ 신- 임+ 계- (`stem_idx % 2 == 0` = 양).
- **지지 십성 = 지장간 본기(마지막 원소) 천간으로 계산.**
  기존 `HIDDEN_STEMS[branch][-1]`이 곧 본기다 (예: 未→['정','을','기']→본기 '기').
- 일간 자기 자신 = 표시상 "일원", 통계 집계상 "비견".
- 검증: 일간 甲 → 辛=정관, 丙=식신, 乙=겁재, 未(기)=정재, 戌(무)=편재, 亥(임)=편인 — 스크린샷 일치 ✓

### 6.2 12운성(十二運星) — 장생 앵커 + 방향 알고리즘

순서(고정): `장생 목욕 관대 건록 제왕 쇠 병 사 묘 절 태 양`

| 일간 | 장생 지지 | 진행 방향 |
|---|---|---|
| 갑 | 해 | 순행(지지 정방향) |
| 병 | 인 | 순행 |
| 무 | 인 | 순행 |
| 경 | 사 | 순행 |
| 임 | 신 | 순행 |
| 을 | 오 | 역행 |
| 정 | 유 | 역행 |
| 기 | 유 | 역행 |
| 신 | 자 | 역행 |
| 계 | 묘 | 역행 |

알고리즘: `offset = (target_branch_idx - 장생_idx) % 12` (양간),
`offset = (장생_idx - target_branch_idx) % 12` (음간) → `순서[offset]`.

- 채택 기준: **양생음사(陽生陰死) 정통설** (양간 순행, 음간 역행). 화토동법 논쟁 있으나
  무=인, 기=유 (수토동법 아닌 화토동법) 채택 — 참조 앱과 동일 계열.
- 검증: 甲(해 장생, 순행): 亥=장생, 未=묘(offset 8), 戌=양(offset 11) — 스크린샷 일치 ✓.
  대운·세운에서도: 午=사, 辰=쇠, 巳=병, 申=절, 酉=태 — 스크린샷 일치 ✓

### 6.3 12신살(十二神殺) — 삼합국 앵커 + 순환 알고리즘

순서(고정): `겁살 재살 천살 지살 년살 월살 망신살 장성살 반안살 역마살 육해살 화개살`

기준 지지(기본: **년지**. 신살/길성 탭은 년지+일지 union — §6.5 참고)의 삼합국:

| 삼합국 | 소속 지지 | 겁살 시작 지지 |
|---|---|---|
| 인오술(火) | 인·오·술 | 해 |
| 사유축(金) | 사·유·축 | 인 |
| 신자진(水) | 신·자·진 | 사 |
| 해묘미(木) | 해·묘·미 | 신 |

알고리즘: 시작 지지부터 지지 정방향으로 12신살 순서를 배정.
(규칙 암기법: 겁살 = 삼합 마지막 글자(묘고지)의 **다음** 지지)

- 검증: 년지 亥(해묘미) → 겁살 신(申)부터: 신겁살 유재살 술천살 해지살 자년살 축월살
  인망신 묘장성 진반안 사역마 오육해 미화개.
  → 未=화개, 戌=천살, 亥=지살 — 스크린샷 일치 ✓

### 6.4 공망(空亡) — 순중공망 알고리즘

일주의 60갑자 인덱스로 순(旬)을 구하고, 그 순에서 빠지는 지지 2개가 공망.

```python
def gongmang_of(day_stem, day_branch):
    i = gapja_index(stem_idx, branch_idx)      # 기존 gapja.py 재사용
    xun_start = i - (i % 10)                   # 순의 첫 갑자 (갑X)
    b = xun_start % 12
    return [EARTHLY_BRANCHES[(b + 10) % 12], EARTHLY_BRANCHES[(b + 11) % 12]]
```

| 순(旬) | 공망 |
|---|---|
| 갑자~계유 | 술·해 |
| 갑술~계미 | 신·유 |
| 갑신~계사 | 오·미 |
| 갑오~계묘 | 진·사 |
| 갑진~계축 | 인·묘 |
| 갑인~계해 | 자·축 |

- 검증: 일주 甲戌(인덱스 10) → 공망 신·유. 사주 지지(미술술해)에 없음 → 전부 "-" ✓

### 6.5 신살/길성 테이블 (참조 앱 등장 10종 — 1차 범위)

**a) 천을귀인 (일간 → 지지, 최고 길성)**
| 일간 | 지지 |
|---|---|
| 갑·무·경 | 축, 미 |
| 을·기 | 자, 신 |
| 병·정 | 해, 유 |
| 임·계 | 사, 묘 |
| 신(辛) | 오, 인 |

검증: 甲 → 未 천을귀인 ✓

**b) 천덕귀인 (월지 → 특정 간지 1글자)**
| 월지 | 인 | 묘 | 진 | 사 | 오 | 미 | 신 | 유 | 술 | 해 | 자 | 축 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 천덕 | 정 | 신(申) | 임 | 신(辛) | 해 | 갑 | 계 | 인 | **병** | 을 | 사(巳) | 경 |

검증: 술월 → 丙 천덕귀인 ✓ (주의: 천간일 수도 지지일 수도 있음 — 사주 8글자 중 해당 글자에 태그)

**c) 월덕귀인 (월지 삼합국 → 천간)**
| 월지 삼합 | 인오술 | 신자진 | 사유축 | 해묘미 |
|---|---|---|---|---|
| 월덕 | 병 | 임 | 경 | 갑 |

검증: 술월(인오술) → 丙 월덕귀인 ✓

**d) 백호대살 (기둥 간지 조합 — 7개)**: 갑진, 을미, 병술, 정축, 무진, 임술, 계축.
해당 기둥의 천간·지지 **양쪽에** 태그. 검증: 월주 丙戌 → 丙과 월지 戌에 백호대살 ✓

**e) 현침살 (글자 모양 — 사주 내 존재만 보면 됨)**: 갑, 신(辛), 묘, 오, 신(申).
검증: 甲·辛 현침살 ✓

**f) 급각살 (월지 계절 → 지지 2개)**
| 월지 | 인묘진(봄) | 사오미(여름) | 신유술(가을) | 해자축(겨울) |
|---|---|---|---|---|
| 급각살 | 해, 자 | 묘, 미 | 인, 술 | 축, 진 |

검증: 술월(가을) → 戌 급각살. **주의**: 참조 앱은 일지 戌에만 태그하고 월지 戌(기준 자신)에는
태그하지 않음 → "월지 자신 제외" 정책 채택, 주석 명시.

**g) 화개살**: 12신살의 화개를 신살/길성 탭에서는 **년지 기준 + 일지 기준 union**으로 태그.
검증: 년지 亥(해묘미)→화개 未, 일지 戌(인오술)→화개 戌 → 未·戌·戌 모두 화개살 ✓
(사주원국 표의 12신살 행은 년지 기준만 사용 — 두 곳의 기준이 다름에 주의)

**h) 문곡귀인 (일간 → 지지)**: 문창귀인의 충(冲) 지지라는 유도 규칙 채택.
| 일간 | 갑 | 을 | 병 | 정 | 무 | 기 | 경 | 신 | 임 | 계 |
|---|---|---|---|---|---|---|---|---|---|---|
| 문창 | 사 | 오 | 신 | 유 | 신 | 유 | 해 | 자 | 인 | 묘 |
| 문곡 | 해 | 자 | 인 | 묘 | 인 | 묘 | 사 | 오 | 신 | 유 |

검증: 甲 → 亥 문곡귀인 ✓ (다른 일간은 참조 앱 추가 대조 필요 — 리스크 §11)

**i) 학당귀인 (일간 → 12운성 장생 지지)**: §6.2 장생 표 재사용.
검증: 甲 장생=亥 → 학당귀인 ✓

**j) 암록 (일간 → 건록 지지의 육합 지지)**
건록: 갑인 을묘 병사 정오 무사 기오 경신 신유 임해 계자 →
| 일간 | 갑 | 을 | 병 | 정 | 무 | 기 | 경 | 신 | 임 | 계 |
|---|---|---|---|---|---|---|---|---|---|---|
| 암록 | 해 | 술 | 신 | 미 | 신 | 미 | 사 | 진 | 인 | 축 |

검증: 甲 → 亥 암록 ✓

**2차 확장 후보(같은 패턴, 테이블만 추가)**: 역마살·도화살(=년살, 12신살에서 파생),
괴강살(경진·경술·임진·임술), 양인살(갑묘 병오 무오 경유 임자), 홍염살, 귀문관살, 천라지망.

### 6.6 합충형파해 (사주관계 "천간과 지지" 서브탭)

`compat.py`에 이미 있는 상수(육합/삼합/충/원진)는 `relations.py`로 이동하고 compat이 import.

- **천간합(合)**: 갑기→토, 을경→금, 병신→수, 정임→목, 무계→화
- **천간충(沖)**: 갑경, 을신, 병임, 정계
- **지지육합**: 자축→토, 인해→목, 묘술→화, 진유→금, 사신→수, 오미→화(토)
- **지지삼합**: 신자진→수, 해묘미→목, 인오술→화, 사유축→금 (2글자만 있으면 "반합")
- **지지방합**: 해자축→수, 인묘진→목, 사오미→화, 신유술→금
- **지지충**: 자오, 축미, 인신, 묘유, 진술, 사해
- **형(刑)**: 인사신(무은지형), 축술미(지세지형), 자묘(무례지형), 진진·오오·유유·해해(자형)
- **파(破)**: 자유, 축진, 인해, 묘오, 사신, 미술
- **해(害)**: 자미, 축오, 인사, 묘진, 신해, 유술
- **원진(怨嗔)**: 자미, 축오, 인유, 묘신, 진해, 사술

출력 형식: 4주 지지의 모든 쌍(4C2=6쌍) + 인접 3글자 조합을 검사해
`[{'kind': '삼합', 'members': ['묘','미'], 'note': '해묘미 목국 반합', 'pillars': ['년','시']}, ...]`

### 6.7 오행 % · 십성그룹 · 상태배지

- 가중치: **8글자 균등 1/8 = 12.5%** (시주 없으면 6글자 균등 16.67%). 지장간 가중 없음
  — 참조 앱 값(12.5 단위)과 일치하는 가장 단순한 방식.
- 십성그룹: 비겁=비견+겁재, 식상=식신+상관, 재성=편재+정재, 관성=편관+정관, 인성=편인+정인.
  **일간 자신은 비견으로 집계** (검증: 비견 12.5% ✓).
- 상태배지 (글자 수 기준, 8글자일 때):

| 개수 | 0~1개 | 2개 | 3~4개 | 5개 이상 |
|---|---|---|---|---|
| 배지 | 부족 | 적정 | 발달 | 과다 |

검증: 목2=적정, 화1=부족, 토3=발달, 금1=부족, 수1=부족 ✓
(6글자 사주일 때: 0~1 부족, 2 적정, 3 발달, 4+ 과다 — 참조값 없으므로 잠정, 주석 명시)

### 6.8 신강신약 — 점수제 (참조 앱 스크린샷 없음 → 잠정 규칙, 반드시 대조 후 튜닝)

방법론(투명한 가중 점수):
```
돕는 세력(+) : 인성·비겁 글자
빼는 세력(–) : 식상·재성·관성 글자
가중치       : 월지 본기 3.0 (득령) / 일지 1.5 (득지) / 그 외 지지 1.0
               / 월간·시간 1.0 / 년간 0.8  (일간 자신은 제외)
점수 = Σ(돕는) / Σ(전체)  →  0.0~1.0
등급 : ≥0.75 극신강, ≥0.55 신강, ≥0.45 중화, ≥0.25 신약, <0.25 극신약
부가 : 득령(월지 십성그룹이 인성/비겁 여부), 득지(일지), 득세(돕는 글자 수≥4) 불리언 제공
```
- ⚠️ 유파별 편차가 가장 큰 항목. **"참조용 간이 판정"임을 UI·README에 명시**하고,
  사용자가 참조 앱 신강신약 탭 스크린샷을 제공하면 등급 경계를 튜닝한다 (§9).
