# 궁합 점수 규칙 (saju/compat.py 근거)

> `saju/compat.py`의 `couple_compat`/`team_compat`이 채택한 점수 규칙. 원래는
> 서비스 궁합 화면 전체 설계 문서의 일부였으나, 서비스 UI·카카오 연동·공유
> 이미지 등 서비스 세부사항은 서비스 레포로 이관하고 엔진 로직 근거만 남긴다.

## 궁합 점수 규칙 (기본 50점 시작, 0~100 클램프)

| 요인 | 판정 | 점수 |
|---|---|---|
| 일간 천간합 | 갑기·을경·병신·정임·무계 | +15 |
| 일지 관계 | 육합 +12 / 삼합 +10 / 충 −12 / 원진 −8 | |
| 띠(연지) 관계 | 육합 +8 / 삼합 +8 / 충 −8 / 원진 −5 | |
| 오행 보완 | 한쪽에 없는 오행(0개)을 상대가 채움: 건당 +3 (최대 +12) | |
| 오행 공백 | 둘 다 없는 오행: 건당 −2 (최대 −6) | |

- 지지 관계 정의: 육합(자축·인해·묘술·진유·사신·오미), 삼합(신자진·해묘미·인오술·사유축),
  충(자오·축미·인신·묘유·진술·사해), 원진(자미·축오·인유·묘신·진해·사술)
- 등급: 90+ 천생연분 / 80+ 환상의 짝꿍 / 70+ 아주 좋은 궁합 / 60+ 좋은 궁합 /
  50+ 무난한 궁합 / 40+ 노력이 필요한 궁합 / 그 외 서로 이해가 필요한 궁합
- 팀(3~4인) 궁합은 모든 쌍(pairwise)에 위 2인 궁합을 적용해 평균낸다.
